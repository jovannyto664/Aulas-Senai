    Catch silencioso

    Um catch vazio esconde o problema: o programador perde a informação técnica e o usuário fica sem retorno. O console pode receber detalhes do erro, enquanto a interface deve mostrar uma mensagem simples.

    try {
  const dados = JSON.parse(textoRecebido);
  mostrarDados(dados);
} catch (erro) {
  console.error("Falha ao processar os dados recebidos:", erro);
  mostrarMensagem("Não foi possível carregar os dados. Tente novamente.");
}

    Uso de finally no envio

    No envio válido, o botão é desativado, o livro é validado, salvo e renderizado; no fim, o finally restaura texto e estado do botão. No envio inválido, o catch mostra erro.message e o finally restaura o botão do mesmo jeito, evitando repetição.
